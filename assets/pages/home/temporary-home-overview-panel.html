Lekhak Manch Writing Studio

A focused desk for stories, novels, drafts, names, and world facts.

Create a local writing project, keep every chapter as a real text file, and use smart side boards to remember names, facts, drafts, and chapter structure while you write.

01

Draft Saving System

Write freely inside draft files first, autosave them safely, then promote a draft into the newest chapter when it is ready.

02

Parts and Chapters

Organize long stories like a clean file tree: parts behave like folders, chapters behave like files, and the active part expands automatically.

03

Naming Board

Track characters, places, objects, and custom categories with color states for chapter names, detected names, existing names, and empty categories.

04

Facts: Key + Description

Save story facts with a keyword and full description, see current chapter facts first, then recent facts with quick search.

05

Safe Chapter Editing

Existing chapters stay protected until you unlock editing. Changes go into a temporary draft and can be recovered or discarded later.

06

Local Folder Workflow

Your selected folder stores JSON information, chapter text files, draft files, naming memory, and fact data in a portable structure.
